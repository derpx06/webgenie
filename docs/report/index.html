What changed

Every component, end to end

Security

  • Page text can no longer close the untrusted wrapper and pose as the user.
  • Orders, payments, subscriptions and account changes wait for a confirmation the system writes, used once; the model must state what every click commits.
  • Checks that see only the user's messages guard sending their personal data, opening addresses a page supplied, and uploading their files.
  • Passwords reach the model only as placeholders; routes-only memory stores nothing the user wrote.
  • Personal details nobody gave are never typed or planned.

Human in the loop

  • Looks at the page before asking what the page shows; asks for what only the user has.
  • A refused action is asked again after the user's next message, so a yes lets it through.
  • Never clicks things just to find out what they are.
  • Answers are keyboard-usable; an answered question locks.

Lifecycle

  • Closing the panel or the tab, a detached debugger, no answer, rate limits or a lost connection pause the task, saved; reopening resumes it.
  • A restarted service worker picks the task up again.
  • A late answer resumes a stopped task.

Tools and perception

  • Uploads into file fields, hidden fields behind buttons and drop zones; downloads reported by name.
  • Screenshots only when they help, 1280 px at most, with neutral element labels.
  • Elements an action revealed are marked; clicks pass only on a real change.
  • Values typed into one form must come from one entry of a list; a filled field is not overwritten by accident.

Model calls

  • Per-model time limits, doubled for calls with a screenshot; slow calls duplicated.
  • Rate limits honour the server's hint or back off with a shared cooldown for up to 180 s; spent quota ends the task.
  • “Failed to fetch” waits like a rate limit instead of ending the task in a second.

Harness

  • 106 tasks in 11 suites, each fixture checker proven by a scripted oracle.
  • Wilson intervals, pass on every attempt, needless and missed questions, backoff share, cost, long-task trends.
  • Unreachable start pages and model providers are recorded apart and left out of pass rates.
  • The real side panel is driven from the keyboard (U1).

Outside bar

Online-Mind2Web: ready, waiting on dataset access

The runner, a seeded 60-task stratified slice and a WebJudge-style Gemini 2.5 Pro judge are in chrome-extension/e2e/mind2web. The task file is gated on Hugging Face ("requires approval"); the dataset terms were not accepted on your behalf, and the task list was not rebuilt from other agents' published results. Once access is approved it runs with three commands.
